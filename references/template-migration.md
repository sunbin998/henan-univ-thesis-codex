# 官方模板迁移

用于原 DOCX 与河南科技大学官方示例模板在同样设置下显示差异明显，或者用户要求按官方模板重建前置页、目录、正文结构时。

## 优先级

1. 官方示例模板副本优先。
2. 老师批注优先。
3. 当前论文中已经人工验收的格式可作为局部基线。
4. 不创新规范，不自行发明视觉样式。

## 迁移策略

- 如果同样字体、字号、缩进设置在原文档和官方模板中视觉差异巨大，优先使用官方模板副本作为新文档基础。
- 封面、声明页优先保留模板结构，只替换题目、学生、学院、专业、导师、日期等信息。
- 摘要、目录、正文、参考文献、致谢按模板结构逐块迁移。
- 不要只迁移样式名称，要迁移段落属性、run 属性、页眉页脚、分节符、页码设置和必要的 OOXML 细节。
- 对目录字段要谨慎，已修好的静态目录不要在未确认前自动更新。

## 一对一审查

迁移后按模板结构逐块比对：

- 封面纵向间距与字段排布。
- 声明页标题、正文、签名栏。
- 中英文摘要标题、关键词格式和页眉。
- 目录标题、目录级别缩进、前导符和页码。
- 正文章标题、节标题、子节标题、正文段落。
- 图题、表题、表格三线表样式。
- 参考文献标题前空行、条目字体、编号和对齐。
- 致谢标题格式和正文缩进。

不要只看局部截图。需要按页面顺序查看最终 PDF。
