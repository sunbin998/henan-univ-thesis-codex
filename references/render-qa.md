# Word/PDF 渲染验收

用于任何会影响最终视觉排版的 DOCX 修改，尤其是目录、分页、页眉页脚、图表、表格跨页、参考文献和模板迁移。

## 验收链路

1. DOCX 导出为 PDF。
2. PDF 渲染为 PNG 页面图片。
3. 逐页检查目录、标题、正文、图表、分页、页眉页脚、参考文献和致谢。
4. 发现问题后回到 DOCX 或 OOXML 修复，再重新导出和渲染。

## 工具选择

- 如果容器内 LibreOffice 稳定，可用 LibreOffice 导出。
- 如果 LibreOffice 不稳定，使用主机 Windows Word 自动化导出。
- 不要把 `python-docx` 成功保存当作格式验收。
- 不要只读取 `.docx` 文本判断最终视觉效果。

## 页面检查重点

- 目录是否有 `错误!未定义书签。`。
- 章标题是否另起页，标题前后空白是否与模板一致。
- 正文跨页后左侧起始位置是否自然。
- 表格是否出现行被拆开的残片。
- 图表是否清晰，图题表题是否与图表贴合。
- 页眉文字、页码类型、奇偶页差异是否正确。
- 参考文献和致谢标题前空行是否符合模板。

## 重新分页时

只要修改导致重新分页，就应重新做视觉验收。目录页码、图表位置、跨页表格和后置部分是高风险区域。
