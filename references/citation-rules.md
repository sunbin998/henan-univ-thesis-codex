# 引用与参考文献规则

用于正文引文标示、参考文献顺序、上标格式和引用密度清理。

## 正文引用

- 引文标示必须为方括号上标。
- 标准形式是 `……研究[1]`，其中 `[1]` 设置为上标。
- 引用放在真正需要支撑的句子末尾。
- 各级标题不得使用引文标示。
- 不要出现普通正文 `[1]`。
- 不要出现 `[1][2][3][4]` 这类密集堆叠。
- 同一处若必须多引，原则上不超过 2 篇。

## 顺序策略

如果采用“参考文献在正文中首次顺序引用且只出现一次”的策略，必须全文一致：

- 正文首次出现顺序应与参考文献表编号一致。
- 参考文献表中的每篇文献都必须在正文中出现。
- 删除正文引用时同步检查参考文献表。
- 调整参考文献顺序后同步调整正文编号。

## 第一、二章

第一、二章不能为了引用而引用，但也不能几乎没有引用。研究背景、国内外现状、核心技术依据和需求分析中的事实性判断，才是适合放引用的位置。

## OOXML 检查

用 `python-docx` 设置上标后，仍应抽查对应 run：

- `[n]` 文本是否单独或可控地位于上标 run。
- `w:vertAlign` 是否为 `superscript`。
- 上标 run 是否没有继承不必要加粗、字体漂移或错误字号。
